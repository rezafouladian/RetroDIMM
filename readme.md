## Detailed Signal Descriptions

### CLOCK

If you do not provide a clock, some RAM modules may not work.

### DIR

Direction control for bus transceivers on the module.

For writes (controller to module) this should be high. For reads (module to controller) this should be low.

### <span style="text-decoration:overline">DOEH</span> & <span style="text-decoration:overline">DOEL</span>

Output enable signals for the high byte and low byte of the data bus transceivers. When low, the output of the bus transceiver will be enabled.

If you are designing a board to support more than one module, each module will need its own <span style="text-decoration:overline">DOEH</span> & <span style="text-decoration:overline">DOEL</span> signals to prevent bus contention.

### RAM_[N]MB

Indicates the size of the RAM available on the module. Allows the controller to properly map or divide the memory space.

The size is defined across 7 total bits, and you can set a combination of the bits to get the desired size.  
With no bits set, the RAM size will be indicated as 512KB. With all 7 bits set, the RAM size will be indicated as 128MB.

Example Sizes:
| Size | RAM_1MB | RAM_2MB | RAM_4MB | RAM_8MB | RAM_16MB |
| --- | :-: | :-: | :-: | :-: | :-: |
| 512KB | - | - | - | - | - |
| 1MB | X | - | - | - | - |
| 2MB | - | X | - | - | - |
| 3MB | X | X | - | - | - |
| 4MB | - | - | X | - | - |
| 5MB | X | - | X | - | - |
| 8MB | - | - | - | X | - |
| 10MB | - | X | - | X | - |

(X): Pull down to ground  
(-): Leave floating (Pulled up on controller side)

### ROM_[N]MB

Indicates the size of the ROM available on the module. Allows the controller to properly map or divide the memory space.

Example Sizes:
| Size | ROM_512KB | ROM_1MB | ROM_2MB | ROM_4MB | ROM_8MB |
| --- | :-: | :-: | :-: | :-: | :-: |
| 256KB | - | - | - | - | - |
| 512KB | X | - | - | - | - |
| 1MB | - | X | - | - | - |
| 2MB | - | - | X | - | - |
| 4MB | - | - | - | X | - |
| 8MB | - | - | - | - | X |

(X): Pull down to ground  
(-): Leave floating (Pulled up on controller side)

### <span style="text-decoration:overline">RAM_CS[1/2/3/4]</span>

Chip select signals for RAM on module.

If the module only has one 16-bit or two 8-bit chips, you will only need to use <span style="text-decoration:overline">RAM_CS1</span>.

### VPP

Used only for programming ROMs on module that require a specific programming voltage.
